To start, could you walk me through the high-level architecture of the RAG system you built for the customer support portal?

Sure. The user query comes in through an API gateway, gets passed to an embedding model—we used OpenAI's text-embedding-ada-002—and then that vector is used to search a Pinecone vector database. The top 5 results are retrieved, injected into a prompt template, and sent to GPT-4 to generate the final response.
