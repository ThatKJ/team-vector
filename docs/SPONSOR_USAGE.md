# 🏢 Sponsor Technology Usage

> **Purpose**: Track every sponsor technology used in the project. This document helps explain sponsor integration during judging.  
> **When to update**: When a sponsor technology is added, its usage expands, or integration details change.

---

## Integration Philosophy

> **Rule**: Never force a sponsor technology into the product. Only integrate when it genuinely improves the user experience or developer workflow. Judges can tell the difference between meaningful integration and checkbox-ticking.

## Sponsor Integration Scoring Guide

For each sponsor, self-evaluate before submission:

| Criteria | Score (1-5) | Notes |
|---|---|---|
| **Meaningful integration** | Is it core to the product, or bolted on? | |
| **Technical depth** | Are we using it well, or just calling one API? | |
| **User-facing impact** | Can judges see the sponsor tech in action? | |
| **Documentation quality** | Can we explain why we chose it? | |
| **Demo-ability** | Can we show it working in 30 seconds? | |

## Talking Points for Judges

Prepare answers for these common sponsor-related questions:

| Question | Answer Template |
|---|---|
| "Why did you choose [sponsor]?" | "We chose [sponsor] because [specific product need]. Without it, we would have had to [alternative], which [tradeoff]." |
| "How deeply did you integrate it?" | "We use [sponsor] for [specific features]. Here's an example: [brief demo or explanation]." |
| "Could you have built this without [sponsor]?" | "We could have [alternative], but [sponsor] allowed us to [specific advantage] in the limited hackathon timeframe." |
| "What surprised you about [sponsor]?" | "We didn't expect [discovery]. This led us to [how it improved the product]." |

---

## Best Practices

1. **Integrate early**: Don't leave sponsor integration to the last hour
2. **Go deep, not wide**: Better to deeply integrate one sponsor than superficially use three
3. **Document as you go**: Update this file with every integration step
4. **Make it demo-able**: If you can't show it, it doesn't count
5. **Be honest**: If a sponsor tech wasn't the best fit, explain what you learned
