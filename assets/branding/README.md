# Branding Assets

Place brand assets (logos, icons, favicons, OG images) in this directory.

## Naming Convention

- `logo.svg` — Primary logo (SVG preferred)
- `logo-dark.svg` — Dark mode variant
- `icon.png` — App icon (512x512)
- `favicon.ico` — Browser favicon
- `og-image.png` — Open Graph image (1200x630)

## Guidelines

- Use SVG for logos when possible (scalable)
- Provide dark mode variants for logos on dark backgrounds
- Keep file sizes optimized
- Maintain consistent brand colors (reference design tokens)
