# Screenshots

Capture screenshots of the application at key stages for:
- Documentation and progress tracking
- Demo backup (in case live demo fails)
- Hackathon submission materials
- README and presentation assets

## Naming Convention

Use descriptive names with timestamps:
- `01-landing-page.png`
- `02-core-feature.png`
- `03-ai-interaction.png`
- `04-results-view.png`
- `05-mobile-responsive.png`

## Capture Checklist

- [ ] Landing page (desktop)
- [ ] Landing page (mobile)
- [ ] Core feature in action
- [ ] AI-powered feature
- [ ] Loading states
- [ ] Empty states
- [ ] Error states (for documentation, not demo)
