# Demo Assets

Store demo-related assets here:
- Pre-recorded demo video (backup for live demo failure)
- Demo data files (seed data for realistic demonstrations)
- Presentation slides (if applicable)
- Screen recordings of specific features

## Naming Convention

- `demo-video-final.mp4` — Complete demo recording
- `demo-data.json` — Seed data for demo
- `feature-X-recording.mp4` — Individual feature recordings

## Pre-Demo Checklist

- [ ] Record a complete backup demo video
- [ ] Prepare seed data that looks realistic
- [ ] Test the demo flow end-to-end
- [ ] Ensure all assets are committed to the repo
